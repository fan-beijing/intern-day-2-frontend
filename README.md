# 雪庐记账 · 前端（intern-day-2-frontend）

第二天练习项目：登录鉴权 + 个人记账的 React 前端，调用真实后端接口，不使用前端 Mock。

## 项目主题

登录后记账，按月份查看明细与汇总。页面风格为水墨 + 宣纸 + 朱砂。

## 功能范围

**必做**：登录页（账号、密码、错误提示、加载状态）、登录后展示后端返回的当前用户、退出登录、未登录不能进入功能页。

**自选功能**：个人记账——记一笔（收入/支出、金额、日期、分类、备注）、按月查看明细、查看月度汇总、删除一笔。

**暂不做**：注册、找回密码、第三方登录、角色权限。

## 验收条件

- 登录、当前用户、退出全部走后端接口，前端不判断账号密码。
- 未登录访问 `/ledger` 返回登录页；接口返回 `401` 时清理本地登录态并提示重新登录。
- 刷新页面的行为与 README 一致：保持登录，但重新向后端校验。
- 加载中、空数据、请求失败、提交中都有对应提示。

## 页面

| 路由 | 说明 |
| --- | --- |
| `/login` | 登录页 |
| `/ledger` | 记账页，受登录保护 |

## 接口约定

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| POST | `/auth/login` | 登录，返回令牌与用户信息 |
| GET | `/auth/me` | 获取当前用户（刷新时校验登录态） |
| POST | `/auth/logout` | 退出登录 |
| GET | `/ledger/entries?month=YYYY-MM` | 按月读取本人账目 |
| POST | `/ledger/entries` | 新增账目 |
| DELETE | `/ledger/entries/{id}` | 删除本人账目 |
| GET | `/ledger/summary?month=YYYY-MM` | 月度收支汇总 |
